# Projeto Git e GitHub - WoMakersCode
Bem-vindo ao repositório do __Projeto do Módulo 2 do Curso de Git e GitHub - WoMakersCode__! Este projeto foi desenvolvido como parte das atividades práticas do curso, com o objetivo de colocar em prática os conceitos de **adição**, **commit** e **push** no Git e GitHub.

## 📝 Descrição do Projeto
Este repositório contém arquivos HTML simples que foram utilizados para demonstrar os seguintes conceitos:

- Como criar e adicionar arquivos ao repositório local.
- Como realizar commits para salvar alterações localmente.
- Como enviar alterações para um repositório remoto com o comando ```git push```.

## 📖 Conhecimentos Praticados
Durante este projeto, você praticará os seguintes comandos e conceitos do Git:

- **```git init```**: Inicializar um repositório local.
- **```git add```**: Adicionar arquivos ao stage.
- **```git commit```**: Criar um ponto de salvamento.
- **```git push```**: Enviar alterações para o repositório remoto.
- **```git status```**: Verificar o status dos arquivos no repositório.

- **GitHub**: Plataforma de hospedagem de código.

## 🌟 Contribuindo
Se você deseja contribuir para este projeto, sinta-se à vontade! Basta seguir os passos:

1. Faça um fork do repositório.
2. Crie uma nova branch para suas alterações:
```bash
  git checkout -b minha-contribuicao
```
3. Faça as alterações desejadas e realize um commit.
4. Envie suas alterações para o seu fork:
```bash
  git push origin minha-contribuicao
```
5. Abra um Pull Request neste repositório.
